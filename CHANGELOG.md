# Changelog

## 0.2.0 (2026-10-08)

- New `wasmJs` target, so `Blob` also runs in the browser.
- Web sample: an interactive explainer of the blob math, published at https://piotrprus.github.io/KBlobs/demo/.

## 0.1.0 (2026-09-25)

- First release: `Blob`, `BlobLayer` and `BlobPresets.aura`.
- Per-layer color or brush, alpha, segments, amplitude range, tempo, rotation, spin, blur, blend mode, stroke width and visibility.
